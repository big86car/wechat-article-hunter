# Layout Rules

- Body: 16px equivalent, line-height 1.75–1.9, dark gray rather than pure black.
- H2: visible section boundary with restrained accent; do not number automatically.
- H3: smaller but distinct; avoid four or more heading levels.
- Paragraph: 0 0 1em; do not indent with full-width spaces.
- Blockquote: subtle background and left border with sufficient contrast.
- Image: max-width 100%, centered; include informative alt text and optional caption.
- Links: preserve destination and distinguish visually without relying only on color.
- Lists: use only for parallel items and maintain enough left padding on mobile.
- Avoid external CSS, JavaScript, unsupported interactive elements, excessive colored blocks, and decorative emoji repetition.
