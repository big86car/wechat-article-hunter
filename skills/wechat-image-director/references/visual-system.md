# Visual System

Choose one system per article:

- **Editorial analysis:** restrained palette, one conceptual cover, evidence-oriented diagrams.
- **Technical explainer:** clean geometric forms, annotated flows, screenshots only when current.
- **Product review:** real interface/product evidence, consistent crops, neutral comparison frames.
- **Research interpretation:** charts and conceptual diagrams that distinguish result from inference.
- **Opinion essay:** metaphorical cover plus few inline visuals; avoid fake documentary scenes.

Keep a stable palette of 2–3 main colors, one illustration language, one border/radius convention, and consistent caption styling. Avoid brand logos unless relevant and permitted. Never encode essential meaning by color alone.
