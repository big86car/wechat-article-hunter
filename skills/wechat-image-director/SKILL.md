# WeChat Image Director

Treat each image as part of the article's argument. Read `article.md`, the brief, and any brand guidance. Use image generation for original raster art when available; use code-native diagrams/charts for precise information; use search only when real people, places, products, or events must be depicted accurately.

## Build `image-plan.md`

For every proposed visual record:

- ID, placement, communication purpose, and what the reader should understand
- format: cover, photo, illustration, diagram, chart, screenshot, or quote card
- source mode: generated, retrieved/licensed, user-provided, or code-rendered
- aspect ratio and minimum dimensions
- art direction or exact data/specification
- alt text, caption, source/rights status, and filename

Use [references/visual-system.md](references/visual-system.md) to keep the set coherent.

## Cover

Create one strong focal idea at approximately 2.35:1, with safe space for platform cropping. Prefer little or no generated text because Chinese typography may be unreliable. If text is necessary, add it with a deterministic layout tool after image generation. The cover must accurately represent the article's actual thesis.

## Inline Visuals

Insert visuals only where they compress a complex comparison, clarify a process, ground a real-world subject, or create a necessary reading pause. Do not generate an image for every heading. Charts require verified data and source notes; diagrams require exact labels and relationships.

When using retrieved images, retain the source URL, creator/license information where available, and usage rationale. Never imply a generated scene is documentary evidence.

## Gate

Confirm visual consistency, factual accuracy, legible mobile composition, valid paths, useful alt text, and rights status. Update image markers in the article or provide an explicit replacement map for the layout skill.
