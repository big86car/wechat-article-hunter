# Research Routes

| Type | Inspect first | Add context from | Common failure |
|---|---|---|---|
| News/event | official announcement, filing, transcript | independent reporting, prior timeline | repeating the announcement as verified outcome |
| GitHub project | repository, docs, releases, issues | benchmarks, alternatives, practitioner discussion | describing README claims as tested facts |
| Research paper | paper, appendix, code/data | related papers, critiques, replication | turning correlation into causation |
| Product review | official docs, pricing, hands-on evidence | competitors, user reports | claiming personal testing that did not happen |
| Tutorial | official documentation and version | minimal reproducible test, known limitations | stale syntax or skipped prerequisites |
| Opinion/analysis | original evidence behind premise | opposing views, historical parallels | presenting inference as fact |
| Policy/finance/health | regulator or authoritative body | qualified analysis | unsourced high-stakes guidance |

When a source has commercial incentives, record that relationship. For repositories, check current release dates and unresolved issues. For papers, distinguish preprint status from peer review.
