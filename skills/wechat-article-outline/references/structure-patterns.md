# Structure Patterns

- **News analysis:** event → what changed → why it happened → stakeholder impact → counterpoint → judgment.
- **GitHub/project analysis:** reader problem → project approach → how it works → evidence/limitations → alternatives → who should care.
- **Research interpretation:** question → method → finding → what it does not prove → practical meaning → open questions.
- **Product review:** use case → evaluation criteria → observed evidence → strengths → tradeoffs → alternatives → verdict by user type.
- **Tutorial:** desired result → prerequisites → mental model → steps → verification → failure modes → next extension.
- **Opinion essay:** tension → thesis → evidence chain → strongest objection → synthesis → implication.
- **Framework/explainer:** problem → model → components → worked example → boundaries → application checklist.

Choose one dominant structure. Hybridize only when the topic genuinely requires it.
